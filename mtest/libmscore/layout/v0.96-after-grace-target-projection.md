## Read-only projection

buildGraceAfterGeometry4 returns a fresh GraceAfterPlan4 plus two typed shapes:

- source: the owning chord's own components, in source-segment coordinates;
- target: the following chord's components plus planned after-graces, in
  target-segment coordinates.

Exclude the old after-grace footprint and known aggregate spacing bounds from
the source exactly once. Keep the original following chord's components and
append each grace at its planned target-relative position, retaining the real
Element pointers and identities. Do not transfer musical ownership, overwrite
native segment shapes, or move notes. Rejection leaves the caller's plan and
both shape outputs unchanged.

The source-component filter is shared with v0.95's live clearance check;
the refactor preserves that check's admission and publication behavior. The
new projection is not called by live layout or the system planner yet. AG1-AG3
are supported; AG4-AG6 still reject. Default collision queries still reject
these grace items without a separately validated system context.

This projection prepares system spacing to measure the complete owning-note
to-after-group interval rather than merely accepting the space left by native
spacing. It does not implement that system-plan integration by itself.
