## Source-backed target

spacingElementShape4(mainChord) recursively extracts notes and grace chords
while resolving the native main-chord shape. Grace packing then asks for
individual member shapes again; source projection can recurse into those
same members once more. Repeated extraction repeats native shape queries,
candidate construction and ownership/provenance reconciliation.

Add an optional SpacingShapeCache4, keyed by source item identity, within one
read-only grace query. Recursive extraction populates snapshots for children.
Later extraction of an unchanged child returns a copy of that resolved shape.
Share the cache across combined packing and source projection; standalone
packing gets its own local cache. Uncached callers retain the previous path.

Cache only already resolved raw local snapshots. Preserve every rectangle,
ordering, identity, aggregate owner, shared item, ambiguity and unknown native
component. Keep native shape reconciliation on misses and all component/pair
admission checks afterward. Packing translations affect returned copies, not
cached local shapes. Do not retain snapshots across query boundaries, beam
layout, edits, style changes or publication. The read-only packing/projection
functions do not modify score items or their positions.

No pruning of child obstacles, guessed ownership, padding adjustment or
beam/slur layout change is introduced. This targets shape extraction, not
the separate distance-policy cost or the number of complete geometry queries.
