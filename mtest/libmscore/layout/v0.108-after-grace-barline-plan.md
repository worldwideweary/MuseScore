## New read-only scope

Add buildGraceAfterBarlinePlan4, returning the established GraceAfterPlan4
target-relative positions and typed extents. It shares the existing after-grace
packing implementation but selects only a same-measure ending barline at the
measure end. The old buildGraceAfterPlan4 wrapper still selects chord/rest
targets only. Production geometry, local publication and system planning keep
calling the old wrapper, so rendered layout remains unchanged.

Accept only the first voice of an ordinary pitched staff, a normal visible
autoplaced unmodified single-staff barline with magnitude 1, default spans,
finite coordinates and no attachments. Existing strict owner/member/beam and
single-voice guards remain. Reject repeat/double/final/custom-span/hidden/edited
barlines, merged before-graces and other unsupported targets atomically.

Use the selected barline's identified leaf shape. Extend the explicitly scoped
after-grace pair policy to allow a selected barline; default unscoped grace
queries remain rejected. Grace-to-barline padding follows the existing typed
noteBarDistance entry scaled by mean item magnification. It does not use the
grace-to-note/rest minimum. Preserve the accumulated-group packing and source
grace-to-main safety bound, as audited in v0.107. No musical ownership changes
and no cached native shapes are rewritten.
