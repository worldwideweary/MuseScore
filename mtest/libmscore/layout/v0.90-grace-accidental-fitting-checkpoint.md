# v0.90: accepted A1-A6 checkpoint and narrow-system tests

The user reports that the mtest passes after v0.89. The supplied blue Evolution
and white Studio 4.7.5 captures show broadly comparable A1-A6 horizontal
placement in both justified and natural layouts, with no obvious accidental
collision calling for another adjustment. This accepts the scoped early
grace-beam preparation against these controls; it does not establish which
individual late component caused the earlier A3 difference. Slur curves still
have small differences and remain outside this horizontal-spacing change.

## New controls

Both files save beamLayout4=1 and spacingLayout4=1. Musical content and local
slur connectors are copied from the accepted v0.86 natural control.

| File | Cases | Purpose |
| --- | --- | --- |
| v0.90-spacing-grace-accidental-fitting.mscx | F1-F6 correspond to A1-A6 | Narrow page, no forced breaks, automatic system fitting |
| v0.90-spacing-grace-accidental-squeeze.mscx | S1 corresponds to A3 | Isolated down-stem grace group with main natural, measure stretch 2, narrow page |

The fitting control has page width 6 inches and printable width 4.8 inches.
The squeeze control has page width 3.2 inches and printable width 2 inches.
Both have last-system fill limit 0. The isolated A3 receives an explicit 4/4
time signature and retains its explicit down-beam direction. Labels are short
to make the narrow controls easier to inspect.

v0.82 controls and add these scores under both beam modes. The fitting test
checks actual collection at three widths, full applied measure/segment plans,
group positions, repeated layout, and spacing-off restoration. The squeeze
test computes a target strictly between natural and compressed plan widths,
then checks actual compressed placement and the same stability/restoration
properties. No assertions or tolerances are relaxed. No production code changes.
