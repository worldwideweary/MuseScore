# v0.139 WIP: independent two-staff slur-offset updates

Apply after v0.138. WIP implementation checkpoint: a84adb8.

## Change

Extend the verified offset-only slur update to one or two visible pitched
staves on one music system and one page in Page view. Keep the same command
classifier, property/anchor/generation proof, undo bookkeeping, vertical-fit
guard and native system/skyline/page pipeline. No horizontal plans or system
collection are necessary for an accepted pure offset edit.

The additional two-staff preflight scans every chord/rest in every voice and
its grace notes. Reject staff moves, cross-staff beams, two-note tremolos spanning staves, cross-staff tuplets,
nonpitched staff types and spanners whose ending track is on another staff.
This check happens before restoring or writing layout. It is deliberately
conservative: an unrelated cross-staff object also retains the general path.
The original single-staff shortcut now also explicitly requires pitched staff.

Staff spacing is still recomputed by System::layout2 from fresh skylines;
page placement and final element layout still run. Thus an offset may change
vertical staff distances without rerunning horizontal spacing. Insufficient
vertical page space falls back to the affected-range layout as before.

## Source audit and terminology

The existing generic edit path calls doLayoutRange with the command's dirty
tick range. It starts one measure earlier where possible to account for
headers/cautionary items. System collection and fitting can then propagate
until existing system/page boundaries stabilize. A whole-score request is a
special case of that path, not the meaning of every normal edit update.

The bounded shortcut preserves the existing horizontal geometry of its one
music system. It does not merely repaint or postpone correctness work, and
it does not introduce an edit timer. Multiple systems/pages, linked parts,
additional movements, hidden staves, cross-staff content and other layout
modes still use the existing range path. This stage does not fix N2's separate
ordinary-beam repeat-layout issue or general full-spacing performance.
