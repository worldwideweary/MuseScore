# v0.93: correct the after-grace baseline contract

The supplied result(9).xml fails all four graceAfterBaseline data rows at the
new on/off whole-measure equality assertion. That assertion assumed that
rejecting the full typed system plan would also disable all experimental
rhythmic spacing. The source does not make that promise:

- Measure::computeMinWidth selects Studio rhythmic widths using spacingLayout4.
- Measure::basicStretch returns 1 with that style enabled because duration and
  user stretch are already incorporated in segment widths.
- Measure::stretchMeasure uses Studio segment spring weights with the style on.
- Final-system fill handling is also selected independently of full-plan success.

Consequently, widths and absolute main/grace positions can legitimately change
even though the native after-grace packing algorithm remains in use. This is
a test-contract correction, not a production layout fix.

Replace that whole-measure equality check for AG1-AG5 with the actual local
contract: each after-grace's x relative to its following target segment and its
y remain equal with spacing off/on. The x is computed as ownerSegment.x +
owner.x + grace.x - targetSegment.x. This cancels rhythmic movement of the
source and target while retaining any change in the group's native packing.
Require the expected number of components, preserve the 1e-6 tolerance, and
report case/component/actual/expected values on failure. AG6 remains excluded
from this equality check because its target contains adapted before-graces.

Keep all existing ownership, musical ordering, beam-direction, planner rejection,
rejected-query nonmutation, repeated-layout, round-trip, and complete spacing-off
restoration checks. The complete measure snapshot is still used for repeat and
off-restoration assertions. No production code or score files change.

Local validation: C++11 test syntax. Target Qt runtime validation remains
outstanding. Apply after v0.92 and rerun tst_spacing using the same AG1-AG6
scores. Next: inspect any remaining failures before proceeding to the read-only
after-grace target/packing adapter.
