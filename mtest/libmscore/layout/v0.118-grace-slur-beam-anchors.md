## Source and metrics

Adapt the beamed, non-final, stem-side start branch of pinned Studio v4.7.5
SlurTieLayout::slurPos(), and its forced same-direction main endpoint branch.
Source slurtielayout.cpp blob cc4d7659bffd339ebf6b757d4d70b284812d1fe1.
Additional verified source: engravingitem.h blob
43cc572d85bf5669c5608dc93d73783c8461cbea and engravingitem.cpp blob
12490575cf311df992523739edfaf67baf42613a. magS() includes the score-spatium /
default-spatium ratio; intrinsic chord magnitude maps to Evolution chordMag()
within the already validated ordinary-staff scope.

Preserve the source beamWidthSp expression exactly:
styleS(beamWidth).val() * beam.magS(). It is NOT styleP(beamWidth) * beam.mag(),
and is NOT the nominal beam anchor width introduced by v0.106. Do not silently
correct this expression to a physical drawn-width interpretation.

Start clearance beyond the stem tip is half that source beam term plus
max(0.35 * grace intrinsic magnitude, 0.2) * spatium. Horizontal position uses
stemPosX, a 0.15-spatium grace-scaled beam inset and half the signed stem line
width. Both stem directions use the same source expressions.

When start and target stems agree, the start's stem-side attachment forces the
ordinary unbeamed target endpoint to its stem. That endpoint has clearance
0.35 spatium beyond the stem tip and the corresponding inward 0.15-spatium
horizontal inset. If stems oppose, preserve the supplied legacy end exactly.
No default note-side or floated attachment rules are changed in this stage.

## Scope and integration

Add adjustGraceMergedSlurBeamAnchors4() to graceslurlayout4.cpp/.h. Require
first after-grace to target-main anchors in the existing fully validated joint
geometry, one laid-out system, a beamed non-final start and the slur on that
beam's stem side. Reject edited, unsupported, degenerate or non-finite inputs
without publishing either point. No DOM, user offsets or beam/stem geometry
writes occur in the query.

Slur::slurPos() first computes the existing anchors, then applies this bounded
query only with spacingLayout4 enabled. Opposite-side slurs retain their
v0.117 anchors; unsupported and disabled contexts retain legacy handling.
v0.117's localized curve fitter still performs clearance after attachment,
so final rendered endpoints may subsequently move to clear physical obstacles.
No changes to horizontal packing, style serialization or defaults.
