# v0.109: ordinary barline targets in system spacing

The user reports v0.108 native mtests passing. Enable its bounded normal-barline
packing through the established production geometry/publication path. Preserve
merged-target rejection and Evolution's clearer M2 separation.

## Production integration

buildGraceAfterPlan4 now accepts an ordinary chord/rest or an eligible ending
barline. buildGraceAfterBarlinePlan4 remains a barline-only read-only query.
Both share packing and the existing strict barline/owner/member guards. Double,
heavy final, repeat, edited, spanning, hidden and decorated barlines remain
outside admission. A normal single line explicitly placed at score end can be
accepted because it satisfies the normal-barline geometry scope.

The existing geometry builder stages owner components at source and planned
graces with the selected target at destination. Extend system substitution to
accept a known legacy spacer whose producer is exactly that target barline.
Unknown/mixed/foreign ownership still rejects; source-side and multi-owner
chord validation remain unchanged. Replace projections only after validation.

The established lifecycle now handles barlines: prepare stable grace beam/stem
geometry, prepare complete projections and contexts, solve natural/fitted/
compressed segment intervals, then publish target-relative coordinates in
owner space after final placement. The guarded local publisher also accepts a
normal barline when its native interval has room. No new layout pass or musical
ownership transfer is introduced. spacingLayout4 off keeps native handling.
No beam algorithm or merged-group/M2 direction/spacing rule changes.

## Regression changes

Promote AG4/B1-B3 to normal-barline admission; keep AG6/M1-M3 as rejection
controls. Mixed natural systems containing those merged cases still reject
the complete temporary plan atomically. Remove the obsolete AG4 on/native
target-relative equality assertion while retaining repeat, round-trip and
spacing-off restoration checks. Use SegmentType::All for tested target lookups
and check barline padding without applying the grace-to-note/rest minimum.

New graceAfterBarlineSystem rows cover separate/natural layouts under both
beam algorithms: target type; source/target glyph multiplicity; target-relative
final positions; actual measure/segment geometry against the full plan;
compressed queries; repeat layout and spacing-off restoration. Extend the
existing dynamic actual-compression test with a normal-barline target.

New scores have both experimental styles on and measure stretch 1:

- v0.109-spacing-after-grace-barlines.mscx: B1 up, B2 down, B3 altered, each in
  a separate system, followed by C1 ordinary closing control. That control
  keeps all grace targets normal barlines.
- v0.109-spacing-after-grace-barlines-natural.mscx: same four measures, wide
  page, no forced breaks and natural final-system spacing.
- v0.109-spacing-after-grace-barline-squeeze.mscx: B1 alone, explicit normal
  terminal barline, narrow page and no forced break. The dynamic test derives
  a compressible width from its own plans.
