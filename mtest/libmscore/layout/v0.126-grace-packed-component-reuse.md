## Change

Each combined geometry query previously extracted/validated target and grace
components in packing, then extracted the same components again to construct
its target projection. Packing does not modify score items. Return an optional
private snapshot of those validated physical shapes along with its plan.
The geometry builder reuses that snapshot, preserving target-first order and
then each member in musical order. Store member shapes before packing's
temporary translations and apply each final planned x exactly once. The
target snapshot already includes the target chord's position.

Source-chord components are still extracted separately. Complete identity
checks, failure atomicity and all packing constraints remain. No snapshot
survives the public query; later layout, beam preparation and edits extract
fresh inputs. Standalone public planning APIs are unchanged. The optional
snapshot is collected only when a geometry builder requests it.

This removes a second target/member extraction round inside each successful
combined geometry query. It does not reduce the number of geometry queries,
change convergence passes, defer keyboard layout, or weaken engraving rules.
