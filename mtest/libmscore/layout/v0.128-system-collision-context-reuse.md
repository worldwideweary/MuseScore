## Change

Grace-specific queries already use local chord-eligibility reuse. The generic
system shape-distance and collision-projection queries still checked the same
chords once per component pair. Add an optional query-cache argument to the
generic pair policy and use the existing SpacingContextCache4 implementation
inside each complete shape-distance/projection query.

The generic policy still derives grace admission and checks membership for
each pair. Every item still checks its own validity; pair-specific padding,
shape intersections, scaling, kerning and distances are unchanged. Reuse
records only the existing chord eligibility predicate, including rejections.
The cache is local to one read-only query and clears when its grace flag or
context changes. Nothing is retained across geometry queries, plans or edits.
Shape provenance, shared ownership and atomic-rejection rules are unchanged.
