## Correct coordinate source

Beam::layout2() constructs the first full beam segment as:

    x2 = first.stemPosX() + first.pageX() - beam.pagePos().x()
    if (first.up()) x2 -= first.stem().lineWidthMag()

The beam is drawn in beam-local coordinates. Adding its page x and subtracting
system page x cancels the beam-origin terms. Therefore the live leading edge
for this validated first up-stem branch is:

    first.pageX() - system.pagePos().x()
        + first.stemPosX() - first.stem().lineWidthMag()

Use that exact expression and add half slurEndWidth for the rounded visible
tip, retaining the user's v0.119 alignment preference. Do not read a cached
primary segment or a cached beam origin. This also avoids an extra note-local
centering contribution: Beam::layout2 uses the chord's pageX directly.
