# v0.102: ordinary rest targets for after-graces

The user committed the v0.101 passing-checkpoint cleanup. This stage addresses
the ordinary rest target needed for AG5. Visual success is not yet established;
its previously cramped owning-C-to-first-after-D gap remains the specific
comparison to verify.

## Reference and scope

The pinned Studio 4.7.5 TLayout::layoutGraceNotesGroup packs the entire group
against the appended segment's staff shape. That shape can contain a following
rest. The existing note/rest padding table and grace minimum of 0.45 score
spatium apply; there is no new manual owner-to-grace spacing value.

Extend the existing same-measure, same-voice adapter to a normal visible
undotted rest on the same pitched five-line staff, with magnification 1,
automatic placement, positive duration, and no manual move, beam, tuplet,
lyrics, or attached items. Continue rejecting gap, cue, full-measure and
multimeasure rests, dotted rests, cross-staff/moved rests, other voices,
barline targets, and merged after-/before-grace contexts.

## Implementation

The explicit after-grace collision scope now accepts a chord or rest target
as an Element. Default unscoped queries still reject after-graces. A rest
contributes only its proven own glyph components; unknown, aggregate, foreign,
malformed, zero-size, or attached component geometry rejects transactionally.

Pack backwards against the full accumulated group and the rest shape, retaining
the existing safety bound. Source projection removes the old owning-chord grace
footprints; temporary target projection appends each planned grace once beside
the rest. Staff-shape substitution accepts the rest's direct glyph identity
without casting it to a Chord. Existing producer validation remains intact.

The existing full system fitter, natural placement, compression, beam
preparation, and target-relative publication now consume these rest projections.
Thus owning-note-to-group clearance participates in solving the interval,
instead of trying to squeeze a repacked group into the old native interval.
The guarded local publication path remains available on a mixed fallback
system. Spacing-off retains native layout.

## Tests and comparisons

Update the six-case baseline/query/geometry/local-publication tests to admit
AG5 while keeping AG4/AG6 rejection and mixed-system fallback. Preserve read-only
checks, complete output sentinels, stale-position independence, failed-clearance
nonmutation, repeated layout and spacing-off restoration. Remove only AG5's old
on/off native-packing equality assertion, since its accepted layout now changes.

New graceAfterRest rows test both beam algorithms and both four-case views:
rest glyph present once in target and absent from source; exact target-relative
grace positions; scoped grace/rest padding and unscoped rejection; complete
source-to-target constraint satisfaction; rejection for gap/cue/invisible/manual-
placement rests; actual full-plan measure and segment geometry; repeat/off
restoration. Extend the existing runtime graceSqueeze test with AR1's rest
fixture and require actual compressed segment and grace positions.
