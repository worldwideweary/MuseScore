## Source-backed change

Every merged component-pair policy constructs a temporary grace context
containing three vectors, even when the query-local eligibility cache already
has equivalent roots. Construct that context once in SpacingContextCache4
and reuse it while owner/target identities stay the same. Rebuild its values
when those identities change. The existing value-based eligibility lookup
then invalidates chord decisions if the scope differs. Uncached callers keep
the original local-context construction path.

Do not cache pair-policy results, alter padding, skip membership checks or
retain anything across query boundaries. The prepared context has exactly
the original target-main, owner-after and owner/target-pair vectors. It is
separate from the eligibility key snapshot, so changing roots is observed.
