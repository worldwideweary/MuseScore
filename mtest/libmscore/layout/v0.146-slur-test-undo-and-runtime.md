## Correct the headless test command sequence

The test modeled duration and endpoint commands, but omitted the native
SlurSegment::changeAnchor prefix: push1(ChangeStartEndSpanner). On undo,
ChangeSpannerElements first restores pointers, then the earlier duration
property invalidates the end pointer. The missing prefix must restore the
exact grace endpoint after that invalidation. Musical tick alone cannot
identify a grace chord sharing its parent tick.

Record the native prefix before each synthetic cross-system reanchor,
including return to the original pair. Check the endpoint pointer after
redo too. Keep geometry and published-plan assertions. This stage changes
tests only; it does not modify the engraving or editor algorithms.

Initial recoverable checkpoint: 0aaafc6.

## Bound repetitive traversal work

The full endpoint walk grew expensive because every stop performs command
layout, a fresh full-layout comparison, undo, redo and a final history unwind.
It ran eight times for the beam/staff/direction Cartesian product. Retain the
full eight-combination single-step slurAnchorSpacing4 test. Run the complete
forward/backward musical walk in two representative rows, retaining both beam
styles, both edited staves and both explicit slur directions. Keep all actual
endpoint stops and fresh-layout/undo/redo assertions within those rows.

The cross-system walk uses four pairwise rows: every beam/staff, beam/slur-
direction and staff/slur-direction combination is represented. Keep every
second-system main/grace target, published-plan checks, return across the
break and original curve restoration. No test is skipped, and the assertions
that failed are retained. There are no engraving or application-speed changes.

This cuts long same-system traversal repetitions by 75% and cross-system
repetitions by 50%. These are work-count reductions, not measured wall-time
claims. The prior XML has no per-test duration fields, so exact attribution
of the user's roughly 30-to-160-second increase is unavailable. Native total
time is still needed; it may remain above the old 30-second baseline because
there is meaningful new coverage.
