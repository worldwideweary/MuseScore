Source finding for the architecture audit: spacingMergedGraceSlur4 requires
the first after-grace as start (apart from its separate first-before-grace
local case). forwardAfterGraceSlur4 also requires the first after-grace.
spacingLocalGraceSlur4 requires the first before-grace. Moving the start through
a group can therefore change horizontal admission independently of supported
note geometry. A transition to a supported first-before member may be admitted
again. These are adapter scope restrictions; specialized curve assumptions
must be separated from general horizontal endpoint classification in the audit.

Record start-anchor traversal through every before/after-grace member, followed
by undo/redo, as a regression requirement for that general mechanism. Do not
add another first/second-member special case in response to this report.
