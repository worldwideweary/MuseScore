## Connected implementation

Add an independent ephemeral CmdState slur-anchor candidate. Only a clean,
unlinked, explicitly directed end-anchor edit with unchanged command generation
and both old/new endpoints in the same existing system can request it. Offset
and anchor candidates are mutually exclusive. Reset, ordinary layout requests
and completion of the consuming update clear both. Linked scores, dirty/mixed
commands and multi-system segment handoff keep the general path.

Share the existing bounded native system-elements/staff-distance/page/BSP
update with offset edits. Preserve its one-page, one-music-system, one/two
visible pitched-staff and cross-staff/vertical-fit guards. Anchor edits must
also use the natural-terminal test policy (lastSystemFillLimit exactly 1,
horizontal stretching enabled). Build one fresh spacing plan and compare
all active published horizontal fields before any layout write. Do not fit a fresh
plan to the old width; mismatches use normal affected-range layout. No plan,
chord eligibility or prepared geometry is cached across commands.

The accepted path skips system recollection, prefix fitting and horizontal
republication. Native beam, skyline, slur, staff-distance and page layout still
run. The prefix/anchor/tick undo commands are unchanged. Reanchor undo/redo is
not newly classified; ordinary offset undo/redo retains its existing shortcut.
This bounded first step does not optimize justified/squeezed, cross-system,
automatic-direction or start-anchor edits and makes no native speed claim.

Profiler adds slurAnchorProof and slurAnchorLayout. A proof entry followed by
system entries means normal layout was needed. slurAnchorLayout without system
entries identifies the accepted update; vertical-fit rejection can still yield
both layout markers and normal system work.

report), the build banner confirms optimization off, assertions on, Qt 5.9.9.
