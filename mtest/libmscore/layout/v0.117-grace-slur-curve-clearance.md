# v0.117: localized clearance for combined-grace slur curves

User reports native mtests passing after v0.116. Integrate its verified
physical obstacles into automatic curve computation for exactly that scope.

## Adapted source and bounded differences

Pinned Studio v4.7.5 SlurTieLayout::avoidCollisions(),
addMinClearanceToShapes(), computeArcClearance(), computeAdjustmentBalance()
and computeAdjustmentStep(), slurtielayout.cpp blob
cc4d7659bffd339ebf6b757d4d70b284812d1fe1. Vertical ordering follows
Studio Shape::clearsVertically(), rather than merely intersecting rectangles.

New graceslurlayout4.cpp/.h fits a four-point cubic using separate left,
middle and right collision sections. Inflate intervening note obstacles by
0.4 spatium and other admitted physical components by 0.1; actual target-
owned components receive no additional item inflation. Apply the source's
length/slant-dependent arc-clearance curve. Alternate localized shoulder
movement and endpoint movement for at most 30 passes. Ordinary endpoints use
balance 0.4 and floated anchors 0.9. The caller identifies floated branches
for the validated first-grace / unbeamed-main context; general articulation,
multi-system and cross-staff balancing are outside this stage.

Keep source-backed height and tangent bounds. Deliberate bounded-adapter
differences: include the final sampling interval through the endpoint; check
clearance once more after the last adjustment; reject rather than publish an
uncleared/non-finite/degenerate result; clamp tangent points in the updated
coordinate frame; cap the step magnitude symmetrically for either direction.
Every rejection preserves the input curve. The public query never moves DOM
items. A successful result certifies this sampled clearance test, not a formal
continuous collision proof; dense independent checks supplement it in tests.

## Integration and preservation

SlurSegment::computeBezier() tries the fitter only with spacingLayout4 on,
a single autoplaced unedited segment, no shoulder edit, and the successful
v0.116 combined-grace obstacle collector. Translate physical obstacles into
the segment's local frame, then fit the initial legacy automatic cubic. On
success publish derived endpoints/control points and build the existing
stroke/path/shape from them. No user grip offsets are written. A derived flag
resets on every computation; it prevents the old endpoint-segment-skipping
collision pass from moving the accepted fitted curve afterward.

On rejection use the original legacy curve and collision pass. With spacing
style disabled the legacy path remains active. No score serialization or
style defaults change. Ordinary non-combined slurs are unchanged.

This is a collision/clearance increment, not complete 4.7.5 slur parity. Initial
anchor rules, initial shoulder geometry, staff-line endpoint corrections and
stroke thickness still use Evolution's handling. In particular the separately
audited beam-side anchor offsets remain for the next focused comparison.
