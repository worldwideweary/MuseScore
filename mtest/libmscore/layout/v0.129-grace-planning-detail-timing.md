## Diagnostic change

The remaining after-planning self time includes structural validation, native
shape extraction, padding-table construction, and component-distance work.
Split these before selecting another optimization. Add five opt-in stages:

- `components`: grace component extraction and validation.
- `graceDistance`: accumulated-shape pair policies and distance calculations.
- `paddingTable`: construction of each common-type padding table.
- `elementShape`: native geometry/provenance extraction, including recursive
  calls for component shapes. Inclusive time includes measured descendants.
- `chordCheck`: the structural chord predicate in the after/merged adapter.

Existing self-time subtraction distinguishes measured children. A component
query's self time excludes elementShape and context children; an after-plan's
self time excludes these newly instrumented sections. Do not mistake the
changed breakdown for an optimization. Timing overhead also increases while
profiling, particularly for many short calls.

No engraving, validation, caching, beam, editing, undo or publication rule
changes. All new scopes use the existing startup environment switch. With
MS_LAYOUT4_PROFILE unset they read no clocks and emit no timing output. Add
a compile-time check that each timing stage has a label.
